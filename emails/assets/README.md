# Tipografía para correos

Los SVG contienen trazados de Russo One Regular, no fuentes externas. Se usan como imágenes con texto alternativo en las plantillas. Fuente: https://github.com/google/fonts/tree/main/ofl/russoone. Su licencia SIL Open Font License 1.1 está en `OFL-RussoOne.txt`.

El saludo personalizado y el cuerpo siguen siendo texto HTML para conservar su edición y accesibilidad. Los SVG requieren que el cliente permita cargar imágenes remotas.
